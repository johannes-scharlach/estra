# Hands-on first run

Status: framing only, not shaped. Raised during the onboarding review,
2026-10-13. Builds on `0003-profile-onboarding.md`.

## Problem

Onboarding today is a questionnaire. A new user answers eleven screens and
reaches the account step without having felt what Magpie does. The profile
answers go into a void: nothing shows how they change a meal or a shop.

Meal ideas generated from a near-empty profile read as generic, and a
chat-only first experience feels like "I already have this with ChatGPT".
That is also not how the app is used: a session usually starts from an
ingredient at hand or a dish in mind, and the meal gets worked out together.

## Idea

Right after the email code is confirmed, the user does a few real things in
the app. Being signed in by then means import, planning and chat work as they
do today, with no guest mode:

1. Import at least one recipe they actually want to make, so the app already
   feels like theirs.
2. Pick lunch or dinner for today or tomorrow.
3. Choose what needs buying for it, ticking off what's already at home.
4. Do one "spontaneous meal" session from 2–3 ingredients at hand or a dish
   in mind.
5. Maybe: one meal session that starts from an idea.

## Open questions

- Which profile questions stay up front, and which move into these steps,
  asked when they matter (shops while choosing what to buy, household size
  when planning a meal)?
- With the hands-on part after sign-in, which profile questions still need
  to come before the email step?
- How does step 4 avoid feeling like a generic chatbot?
- How long can the whole run take before people drop off? Which steps can be
  skipped?
- Does closing the app midway resume the first run, or drop the user into
  the normal app?
- Is the walkthrough guided screens, or the real app with prompts on top?

## Not in this spec

The visual redesign of the existing questions. That is the designer brief
from the same review.
