# Onboarding Artwork Style & Prompts

The onboarding and setup artwork uses a **Digital Botanical Watercolor with Geometric Construction** style. It combines organic culinary watercolor washes with sharp, computational geometric construction lines (compass circles, tangent vector arcs, and alignment guides) on a solid background matching the app's light theme (`#FBF8F4` from `apps/mobile/src/global.css`).

## Style Formula

```text
Digital botanical watercolor illustration with sharp geometric precision. [Subject description]. Rendered with ultra-crisp, mathematically exact geometric vector curves, concentric circular construction lines, compass arcs, and alignment guides, filled with translucent generative watercolor blooms, fluid gradients, and soft pigment bleeds. Clean vector lines without any text, words, labels, or lettering. Set on a solid flat background with exact color #FBF8F4 (light warm porcelain off-white). Same composition as reference.
```

### Generation Settings

- **Aspect Ratio**: `1:1` (1024x1024)
- **Background Color**: `#FBF8F4` (theme token `--color-background`)
- **Reference Image**: Provide the target artwork's prior version or composition sketch as input image.
- **Negative / Constraints**: Explicitly prohibit text/labels (`Clean vector lines without any text, words, labels, or lettering`).
