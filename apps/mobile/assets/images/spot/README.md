# Spot Illustrations

Clay-style spot illustrations for Magpie empty states. Handcrafted matte polymer clay aesthetic matching the Magpie mascot reference (`#FBF8F4` warm background, soft top-left studio lighting, smooth plasticine, rounded edges).

All images are formatted as 400×400 PNG.

## Assets

- **Format**: PNG
- **Prompt**: Cute chubby clay magpie looking curiously into an open blank recipe notebook. Handcrafted matte polymer clay style matching the reference image, smooth plasticine, rounded edges, soft studio lighting from top-left, solid flat background with exact color #FBF8F4 as reference image.
- **Usage**: Empty cookbook / recipe list empty state.
